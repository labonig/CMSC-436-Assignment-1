"formatted_data.txt" was created by compiling format.cpp (you may use the commands "make" or "make format"), and running the executable (you may use the command "make run"). This program read the contents of data.csv, calculates additional attributes for positioning and coloring elements of the visualization, and creates a dataset formatted for Vega-Lite.

The code which creates the visualization was developed in Vega-Lite's online editor (https://vega.github.io/editor/#/edited).
The contents of the file "vegalite schema - no data.txt" can be copy-pasted into the editor, and the contents of the file 
"formatted_data.txt" can be copy-pasted where it says "[Paste Data Here]". The output will be the visualization sans caption.
